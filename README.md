# AB Electronics UK ESPHome Libraries
Tutorials and code demos to use the AB Electronics UK range of Raspberry Pi expansion boards with ESPHome.

The tutorials are written for the ESP32-P4, but the board-specific sections work on any ESP32 that ESPHome supports. To use a different ESP32, change the I2C pin numbers to match your board.

The following libraries and code demos are available:

### ADC-Pi-ESPHome-MCP3424
This directory contains tutorials and code to use with the [ADC Pi](https://www.abelectronics.co.uk/p/69/adc-pi)  
### IOPi-Plus-ESPHome-MCP23017
This directory contains tutorials and code to use with the [IO Pi Plus](https://www.abelectronics.co.uk/p/54/io-pi-plus)  
### IOZero32-ESPHome-PCA9535
This directory contains tutorials and code to use with the [IO Zero 32](https://www.abelectronics.co.uk/p/86/io-zero-32)  
### RTCPi-ESPHome-DS1307-Clock
This directory contains tutorials and code to use with the [RTC Pi](https://www.abelectronics.co.uk/p/70/rtc-pi)  
### ServoPi-ESPHome-PCA9685-PWM
This directory contains tutorials and code to use with the [Servo Pi](https://www.abelectronics.co.uk/p/72/servo-pwm-pi)  

For more information on ESPHome, see the [ESPHome documentation](https://esphome.io/).

For more information on AB Electronics UK, see the [AB Electronics UK website](https://www.abelectronics.co.uk/).
